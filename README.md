## 🎯 О проекте

Одностраничный HTML-тренажёр, составленный по **спецификации, кодификатору и демоверсии ФИПИ ЕГЭ-2027 по испанскому языку**. Работает полностью офлайн — достаточно открыть `index.html` в браузере.

Никаких серверов, аккаунтов, рекламы и аналитики.

## ✨ Возможности

- 📝 **42 задания** по структуре ЕГЭ-2027:
  - Аудирование (1–9) — 12 баллов;
  - Чтение (10–18) — 12 баллов;
  - Грамматика и лексика (19–36) — 18 баллов;
  - Письменная речь (37–38) — 20 баллов;
  - Устная часть (39–42) — 20 баллов.
- 🎧 **Аудирование** с встроенным плеером (`audio-es.mp3`) и отдельным аудио для устной части (`audio-es-oral.mp3`).
- 🔍 **Фильтры по разделам**: аудирование / чтение / грамматика / письмо / устная часть.
- ⏱ **Таймер экзамена** с пресетами: 190 мин / 30 мин (аудирование+чтение) / 60 мин / 17 мин (устная).
- ✅ **Частичная автопроверка** заданий с последовательностями (каждая ошибка −1 балл, но не ниже 0).
- 📋 **Чек-лист подготовки** по всем разделам.
- 🗓 **25-дневный план** повторения.
- 🌐 **RU / EN интерфейс**.
- 📱 **Адаптивный дизайн**.
- 🔒 **100% офлайн**, без рекламы и трекеров.
